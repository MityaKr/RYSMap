# Формат карты RYSMap на диске

Папка `<папка игры>/rysmap/<ключ мира>/`.

| Файл | Что | Формат |
|---|---|---|
| `world.json` | имя мира или адрес, когда создан, когда заходили | JSON, `"v": 1` |
| `<пространство>/<путь>/palette.json` | номера блоков и биомов измерения | JSON, `"v": 1` |
| `<пространство>/<путь>/r.<x>.<z>.rmap` | регион 512×512 блоков | свой двоичный, версия в заголовке |
| `<пространство>/<путь>/_broken/` | файлы, которые не прочитались, с датой в имени | как были |

Ключ мира: `sp-<имя сохранения>` в одиночной игре, `mp-<адрес>` на сервере (порт 25565 отбрасывается), позже `w-<UUID мира>` от серверной части. В имени папки только `[a-z0-9._-]`, длинное имя укорачивается с суммой CRC32.

Папка измерения: id `minecraft:the_nether` даёт `minecraft/the_nether`. Двоеточие становится разделителем папок, поэтому обратное имя не угадывается по подчёркиванию.

## palette.json

```json
{ "v": 1, "blocks": ["minecraft:air", "minecraft:stone", "..."], "biomes": ["", "minecraft:plains", "..."] }
```

Номер это место в списке. Номер раз выдан и не меняется. Блок 0 это «нет блока», биом 0 «неизвестный биом». Блоков до 65535, биомов до 255; лишние биомы получают 0. Палитра пишется раньше регионов, поэтому номер в регионе всегда есть в палитре на диске. Если палитра не читается, регионы измерения уходят в `_broken` и карта измерения начинается заново.

## r.x.z.rmap

Все числа big-endian.

| Поле | Размер | Что |
|---|---|---|
| магия | 4 | `RYSM` |
| версия | u8 | 1 |
| слоёв | u8 | в 0.1 всегда 1 (поверхность) |
| x, z | i32, i32 | координаты региона; переименованный руками файл не читается чужим местом |
| на слой: этаж | u8 | 127 поверхность; этажи пещер получат номер секции (0.2) |
| разведанные чанки | i64 × 16 | 1024 бита, бит `z·32 + x` |
| время скана | i32 × 1024 | секунды эпохи; 0 не разведан |
| длина | i32 | сжатых данных слоя |
| данные | длина | Deflate: i16 × 262144 высота, u16 × 262144 номер блока, u8 × 262144 биом, u8 × 262144 вода и свет |
| CRC32 | i32 | всего, что выше |

Столбцы идут строками с севера: индекс `z·512 + x`. Высота `−32768` значит «нет данных» (в разведанном чанке так помечен столбец без видимых блоков). Байт «вода и свет»: нижние 4 бита глубина воды 1–14, 0 без воды, 15 вода без известной глубины (перенос из FTB); верхние 4 бита свет блока 0–15 (для ночи шейдером, 0.2; сканер 0.1 пишет 0).

Запись идёт во временный файл `*.tmp` и переименованием. Файл с плохой магией, версией, суммой или обрезанный уходит в `_broken`, кусок перерисуется при проходе. Регион из 40 чанков занимает около 30 КБ, полностью разведанный около 150 КБ.

## Этажи пещер (0.1.0-m7)

Этаж это слой высотой 16 блоков, номер равен номеру секции (этаж `n` лежит на `16n … 16n + 15`). Карта этажа хранится как отдельное измерение с id `<измерение>/caves/<n>`: папка `<пространство>/<путь>/caves/<n>/` со своей `palette.json` и своими `r.<x>.<z>.rmap` того же формата (поле «этаж» слоя остаётся 127). Столбец этажа: сверху этажа пропускается свод, с первого воздуха спуск до пола (не ниже 16 блоков под этажом); сплошная порода без воздуха помечена «нет данных».
